- Replace underscores with spaces and capitalize each letter . For example:
    - "resident_permit" -> "Resident"
    - "commercial_vehicle" -> "Commercial Vehicle"

ACTIVITY REQUIREMENTS:
- If Purpose = "pickup_dropoff, Ignore the activity value and "Pick-Up/Drop-Off Only" is the activity. 

TIME SPAN REQUIREMENTS:
- Use 12-hour time formats ("H:MM AM/PM").
- If a policy applies all day, do not output time information. Do not use "All Day".

MAXIMUM STAY REQUIREMENTS:
- Format as "Number-Unit" (hyphenated). No other words. 
- Do not pluralizes units.
- Examples:
    - "Parking, 2 hours"  -> "2-Hour Parking"

- Translate "Accessible" to "HP/DV Permit"

    - "Loading for Commercial Vehicles + No Parking Except Commercial Vehicles" -> "Loading Commercial Vehicles"
- "Negative Rule Except" Pattern - reframe as "[ACTIVITY] [USER CLASS] Only".
    - "No Parking Except Residents" -> "Parking Residents Only"
