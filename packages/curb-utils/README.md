# SMART Curb Utilitys

Shared utilities for use with the smart-prototype project.

## Modules

| module       | description                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `ai_client`  | Asynchronous management of Google Gemini queries                                                                                |
| `data_utils` | _Mostly deprecated_ Contains legacy utilities for BigQuery. Utilities for reading data from Google Cloud Storage are still used |
| `db_utils`   | Manage database connections and queries                                                                                         |
| `io_tools`   | Common functions for reading and writing data files                                                                             |
| `logging`    | Set up and context management for logging tools                                                                                 |
